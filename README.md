# Santo Terço

Aplicativo web (PWA) para rezar o terço no celular, contando as contas na tela.

## Terços disponíveis

- **Santo Terço**: mistérios gozosos, luminosos, dolorosos e gloriosos, com escolha automática pelo dia da semana ou manual
- **Terço de São José**
- **Divina Misericórdia**

## Como usar

1. Na tela inicial, toque em **Opções** e escolha o terço, o tema e os demais ajustes.
2. Toque em **Rezar** e, se quiser, escreva uma intenção.
3. Toque na conta destacada para avançar. Tocar numa conta anterior desfaz a marcação.
4. A cruz traz o Sinal da Cruz, o Credo e o Pai Nosso. A conta grande da base é o primeiro Pai Nosso no início e a Salve Rainha no final.

## Recursos

- Três temas de cor (bege, azul e rosa)
- Tamanho da letra ajustável
- Som e vibração opcionais
- Intenção de oração
- Histórico dos terços concluídos
- Progresso salvo no aparelho
- Tela sempre ligada durante a oração (quando o navegador permite)
- Instalável na tela inicial

## Instalação

O app é um único arquivo, o `index.html`, sem dependências.

- **Localmente:** abra o `index.html` no navegador.
- **Online:** publique no GitHub Pages ou em qualquer hospedagem estática. Depois, no celular, use "Adicionar à tela inicial".

## Dados

Tudo fica salvo no próprio aparelho (`localStorage`). Nada é enviado a servidores.
